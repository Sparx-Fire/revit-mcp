## Inno Setup 安装包 RestartManager 崩溃修复
- 现象：Setup.exe 运行时崩溃，日志 `Calling RestartManager's RmGetList` → `Format '可以使用 RestartManager 避免重新启动? %s ' invalid or incompatible with argument`
- 根因：汉化版 `Default.isl`（风铃夜思雨编译）中该消息用 C 风格 `%s` 占位，Inno Setup 6.2.0 运行时 Format() 参数不匹配
- **关键区分（此前误判，务必记住）**：
  - `CloseApplications=no` → 完全不调用 RestartManager API（不执行 RmGetList），**治本开关**
  - `RestartApplications=no` → 仅控制"安装完是否重启被关闭的程序"，**是有效指令**，但不影响 RmGetList 是否执行
- 修复（`plans\mcp-servers-for-revit-安装脚本.iss`）：
  1. `[Setup]` 加 `CloseApplications=no` + `RestartApplications=no`
  2. 注释掉 `[Languages] chinesesimp`（避免加载损坏中文消息表）
  3. `[Code] InitializeSetup` 里 `Exec('taskkill','/F /IM node.exe /T',...)` 释放 runtime\node.exe 文件锁
- **Pascal 语法坑**：`[Code]` 段注释必须用 `//` 或 `{ }`；用 `;` 会导致 ISCC 编译失败（`;` 是语句结束符，不是注释符）
- ISCC 路径（非标准，不在 Program Files）：`C:\_PROM_\DEV\Inno Setup 6\ISCC.exe`
- 验证：重新编译成功（43.4s），产出 `dist\mcp-servers-for-revit_R26_2026_Setup.exe`（38.2MB），无警告
- 副作用提示：`taskkill node.exe` 会结束本机【所有】Node.js 进程

## 修复 Revit MCP commandRegistry.json 为空（12:06-12:27）
- `Commands/commandRegistry.json` 中 `commands` 数组为空 `[]`，导致插件 TCP 服务端收到 JSON-RPC 后全部返回 `"Method not found"`
- 从 `Commands/RevitMCPCommandSet/command.json` 将 84 个命令定义（含 `say_hello`、`get_current_view_info` 等）填充到 `commandRegistry.json`
- **原因**：`commandRegistry.json` 是插件运行时读取的命令注册表，`command.json` 是命令集源定义，安装/部署后没做同步
- **修复方式**：直接写入 67 个命令到 `commandRegistry.json`
- **注意**：需要重启 Revit 使插件重新加载注册表后生效
- **下次修改 MCP 工具时须同时更新两个 JSON**：`commandRegistry.json`（运行时）和 `RevitMCPCommandSet/command.json`（源定义）
