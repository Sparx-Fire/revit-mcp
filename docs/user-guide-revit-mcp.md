# Руководство проектировщика: Revit + Cursor MCP



Пошаговая настройка **без программирования**. Время — около 15 минут.



## Что понадобится



- **Autodesk Revit** 2020–2026

- **Node.js 18+** — [nodejs.org](https://nodejs.org/) (только установить, команды в терминале не нужны)

- **Cursor** — [cursor.com](https://cursor.com)

- **Шаблон проекта организации** (`.rvt`) с дверями, окнами, полами и ведомостями



---



## Быстрый старт (5 шагов)



### Шаг 1. Плагин Revit



1. Скачайте ZIP для вашей версии Revit: [Releases](https://github.com/mcp-servers-for-revit/mcp-servers-for-revit/releases).

2. Распакуйте в:

   ```

   %AppData%\Autodesk\Revit\Addins\<версия Revit>\

   ```

3. Запустите Revit → при запросе об аддине: **Always Load**.

4. Вкладка **mcp-servers-for-revit**:

   - **Revit MCP Switch** → **Open Server**

   - **Settings** → включите **все** команды → **Save**



### Шаг 2. Cursor и папка проекта



1. Скачайте или клонируйте репозиторий `mcp-servers-for-revit`.

2. В Cursor: **File → Open Folder** → выберите **корень** этой папки (где лежат `docs/`, `.cursor/`).

3. Правила агента подключатся автоматически (файл `.cursor/rules/revit-mcp.mdc`).



### Шаг 3. Подключение MCP (без сборки кода)



1. Скопируйте готовый конфиг:

   - из `.cursor/mcp.json.example`

   - в `.cursor/mcp.json`  

   (или выполните скрипт `scripts/setup-user.ps1` — см. ниже)

2. Перезапустите Cursor.

3. В чате должны появиться инструменты MCP (иконка молотка).



### Шаг 4. Проверка связи



1. В Revit откройте **рабочий проект** `.rvt` (не файл семейства `.rfa`).

2. В Cursor напишите:



   > Проверь связь с Revit по правилам revit-mcp



3. В Revit появится окно приветствия. В ответе агента — таблица с `say_hello`.



### Шаг 5. Первый рабочий запрос



Скопируйте и отправьте:



> Работай только через MCP, по правилам revit-mcp. Без send_code_to_revit.  

> Покажи информацию об активном виде и сколько стен в проекте.

## Автоматическая настройка (Windows)



В PowerShell из папки репозитория:



```powershell

.\scripts\setup-user.ps1

```



Скрипт скопирует `.cursor/mcp.json.example` → `.cursor/mcp.json` и выведет чеклист.

## Как заставить агента следовать правилам



| Что делаете вы | Зачем |

|----------------|--------|

| Открываете в Cursor **корень** репозитория | Подтягивается `alwaysApply: true` для `revit-mcp.mdc` |

| В начале запроса пишете: **«по правилам revit-mcp, только MCP»** | Дублирует правило в контексте чата |

| Не просите «создай новый rvt файл» без шага в Revit | MCP не создаёт проект — см. ниже |

| Открываете **.rvt на шаблоне организации** | Есть типы дверей, окон, полов |



Если агент лезет в код или C#:



> Стоп. Только MCP по revit-mcp.mdc. Какие инструменты используешь?



---



## Готовые фразы для чата (копировать)



**Связь**

> Проверь связь с Revit по правилам revit-mcp



**Помещения**

> Выгрузи все данные помещений. Только MCP, без C#.



**Планировка**

> На Level 1 создай комнату 6×6 м: стены, пол, одна дверь, одно окно. Только create_*_element. По правилам revit-mcp.



**Маркировка**

> Промаркируй все помещения на активном виде. По правилам revit-mcp.



**Материалы**

> Посчитай количества материалов. По правилам revit-mcp.



Во всех ответах агент должен перечислить **использованные MCP-функции** в конце.



---



## Новый файл проекта



MCP **не умеет** «Файл → Новый проект». Делайте вручную:



1. Revit → **Файл → Новый → Проект** (шаблон организации).

2. **Сохранить как** `МойПроект.rvt`.

3. В Cursor: «В открытом проекте …» + «только MCP, по revit-mcp».



---



## Что делает агент (и чего не делает)



| Делает через MCP | Не делает |

|------------------|-----------|

| Читает модель, создаёт стены, полы, двери, окна, помещения | Не правит код `server/`, `plugin/` без запроса |

| Выгружает данные для ведомостей | Не пишет произвольный C# (`send_code_to_revit`) без вашего согласия |

| Маркирует, красит для проверки | Не заменяет корпоративные листы и ТЭП |



**ТЭП и ведомости** — оформление в Revit по **вашему шаблону**. Агент даёт данные (`export_room_data`, `get_material_quantities`).



**ГОСТ/СП** в MCP нет — нормы в шаблоне и при проверке проектировщиком.

## Устранение неполадок



| Симптом | Действие |

|---------|----------|

| Нет инструментов MCP | Скопируйте `mcp.json.example` → `mcp.json`, перезапустите Cursor |

| Ошибка при вызове tool | Revit → Settings → включите команду; проверьте **Open Server** |

| «Нет стен / дверей» | Открыт `.rfa` вместо `.rvt` — откройте проект на шаблоне |

| Агент правит код репозитория | «Работай только через MCP, по правилам revit-mcp» |

| Агент использует C# | «Без send_code_to_revit» или явно: «разрешаю C#» |
